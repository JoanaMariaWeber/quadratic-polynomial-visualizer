# Quadratic Polynomial Visualizer

A small JavaScript application developed during my Computer Science studies.

The application accepts the coefficients of a polynomial, validates the input, calculates its real roots and dynamically visualises the function on an HTML canvas.

## Features
- Numerical input validation
- Calculation of linear and quadratic roots
- Discriminant calculation
- Dynamic graph generation
- Visual highlighting of calculated roots

## Technologies
- HTML
- CSS
- JavaScript
- HTML Canvas

This project was created as part of my Computer Science studies.
